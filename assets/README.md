# MusicSCAN artwork

MusicSCAN-badge.png is the square monochrome master badge for project pages,
the website and social posts. It follows the supplied VaultSCAN technical badge.
The musical note identifies MusicSCAN within the SCAN family.

The artwork has no version number so it can be reused for future releases.
The in-game Brewfest icon remains unchanged; this badge is a publishing asset.

Created with the built-in image-generation tool from the supplied VaultSCAN reference.
Prompt brief: a sibling black-and-white circular technical badge, bold MusicSCAN
wordmark, restrained music motif, exact subtitle A World of Warcraft Add-On.
and website www.kilobytes.dev. Preserve distressed rings and compass accents.
